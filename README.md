# ⚡ PlonkMemes

A soundboard definitiva de memes, virais e efeitos sonoros com reprodução instantânea e controles táteis modernos.

## 🚀 Funcionalidades

- **Objetos Sonoros Interativos:**
  - 📼 **Fita Cassete Retrô:** Bobinas dentadas que giram mecanicamente enquanto o áudio toca.
  - 📊 **Cápsula Waveform:** Barras de equalizador acústico animadas em tempo real.
- **Catálogo com mais de 2.300 sons:** Memes clássicos, bordões de TV, efeitos sonoros de games e virais da internet.
- **Armazenamento 100% Local:** Todos os arquivos de áudio servidos com zero latência.
- **Modos de Reprodução:** Modo Solo (interrompe o som anterior) e Modo Caos/DJ (permite sobrepor múltiplos áudios).
- **Busca Instantânea:** Filtro em tempo real por palavras-chave e tags.
- **Upload de Novos Sons:** Formulário com preview de áudio antes da publicação.

## 🛠️ Tecnologias

- [Next.js 16](https://nextjs.org/) (App Router + Turbopack)
- [React 19](https://react.dev/)
- [Tailwind CSS 4](https://tailwindcss.com/)
- [Lucide Icons](https://lucide.dev/)
- [TypeScript](https://www.typescriptlang.org/)

## 💻 Como Rodar Localmente

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no seu navegador.
